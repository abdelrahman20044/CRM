# CRM SaaS

A Customer Relationship Management (CRM) system built with Node.js, Express, and MongoDB.

## 🚧 Status: Under Development

## Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Atlas)
- **Authentication:** JWT

## Getting Started

```bash
# Install dependencies
npm install

# Run in development
npm run dev
```

## Environment Variables

Create a `.env` file:

```env
NODE_ENV=development
PORT=5000
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
JWT_EXPIRES_IN=7d
```
